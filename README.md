# Completando as Operações Matemáticas

Jogo web simples para praticar operações matemáticas.

## Como Jogar

1.  Abra o arquivo `index.html` em seu navegador.
2.  Clique no botão "Iníciar".
3.  Selecione o nível de dificuldade:
    - **Fácil**: Apenas adição.
    - **Médio**: Adição e Subtração.
    - **Difícil**: Adição, Subtração, Multiplicação e Divisão.
4.  Escolha o número de jogadores (de 1 a 4).
5.  Digite os nomes dos jogadores.
6.  Responda o máximo de questões matemáticas que conseguir antes que o tempo acabe.
    - cada jogador tem 60 segundos e 5 vidas.
    - cada acerto vale 10 pontos.
    - cada erro perde 2 pontos e diminui uma vida.
    - se o jogador perder todas as vidas, será a vez do jogador seguinte.
7. Ao fim da partida será exibido a pontuação de cada jogador e o vencedor, quando hover.
